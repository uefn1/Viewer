GitHub Release .TS 連結ビューア

ReleaseのTag URLを貼るだけで out-000.ts ... を自動検出して連結再生。GitHub Pages / ローカルでそのまま動作。CORS対応。
対応URL: /releases/tag/... または /releases/download/... / 直接 out-000.ts のURLでもOK。クエリ ?url=... で自動再生。
待機中 0 files API: 未使用
再生速度 1x
ログ / 取得ファイル
    仕組み
    1. 入力URLから owner / repo / tag を抽出 → api.github.com/repos/{owner}/{repo}/releases/tags/{tag} でアセット一覧取得
    2. .ts で終わるファイルを名前順ソート。失敗時は out-000.ts ~ out-999.ts を HEAD で順に探索 (最大連続404が3で停止)
    3. HLSモード: 取得したURL群からその場で m3u8 プレイリストBlobを生成 → hls.js に食わせてネイティブに連結再生。SafariはネイティブHLS。
    4. Blob連結モード: 全.tsを fetch → Uint8Array連結 → video/mp2t Blobを video.src に。
    GitHubの releases/download は CORS: Access-Control-Allow-Origin: * を返すのでブラウザから直接取得可能。
