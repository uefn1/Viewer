    VLCでも再生できない時のチェックリスト
    1. 0x47 sync byteがない → TSではない。MP4のfMP4セグメントや、暗号化データの可能性
    2. ファイル先頭が ftyp / moof / mdat → fMP4 (CMAF/DASH)。拡張子は.tsだが中身はMP4。MSEで再生可能
    3. エントロピーが高くランダム → AES-128などで暗号化。リリースに key / .key / m3u8 がないか確認。FIFA+はDRMの可能性大
    4. ファイルサイズが極端に小さい / 0 → キャプチャ失敗。go-stream-capturerのログを確認
    5. DRM (Widevine/FairPlay) → ブラウザ/ VLCでは復号不可。ライセンスが必要。Viewerでは対応不可

    この診断版は 1.の判定を自動で行い、2.ならMP4として再生、3.ならAES復号を試みます。Keyがリリースに含まれていれば自動検出します。
